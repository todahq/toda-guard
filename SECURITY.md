# Security

Guard handles accounts, passwords, sessions and tokens, so reports of vulnerabilities are especially welcome.

**Please don't open a public issue for a vulnerability.** Report it privately instead: on this repository's
**Security** tab, choose **Report a vulnerability** (GitHub's private vulnerability reporting), with what you found,
how to reproduce it, and the version. We will answer within a week, agree on a fix and a date to
publish it, and credit you unless you'd rather not be named.

Supported versions: the latest release only, while Guard is in preview (0.x).
